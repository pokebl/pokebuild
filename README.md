# PokéBuild（ポケモンチャンピオンズ構築支援）

ポケモンチャンピオンズ専用の、無料で使える構築支援Webアプリです。
パーティのタイプ相性・素早さ・環境（シングル使用率）を、スマホでも片手でサッと確認できます。

## 使い方（かんたん3ステップ）

1. **ポケモンを入れる**：上の6つの枠をタップ → 下のタイプボタンを押すだけ（簡易入力）。
   名前で入れたいときは「詳細入力」に切り替えると、名前検索・タイプで選ぶ・使用率上位から選ぶ、の3通りでワンタップ登録できます。文字入力は必須ではありません。
2. **結果を見る**：攻撃範囲・耐性は自動で計算されます。下のタブで「攻撃／防御／環境対策／素早さ／補完候補」を切り替えて確認してください。
3. **保存する**：「保存」タブで名前を付けて保存。作った構築はブラウザに自動保存されるので、閉じても消えません。別の端末へは「構築コード」のコピー＆貼り付けで移せます。

## 各タブの説明

- **攻撃**：全18タイプと複合タイプ153通りへの抜群カバー率
- **防御**：攻撃タイプごとに、パーティ全員の被ダメージ倍率表
- **環境対策**：シングル使用率ランキング（上位10/30/50/100切替）に対して抜群が取れるかを表示。取得元・集計期間・最終更新日もここに表示されます。使用率データは手動インポート（CSV: `名前,順位,使用率%` またはJSON）も可能で、自動取得データより優先されます
- **素早さ**：自分のパーティと環境上位を同じ表で比較。通常／1.5倍／2倍の実数値つき。相手を基準に選ぶと「抜くために必要な実数値」と「必要なSP（能力ポイント）」を表示します。細かいSP調整は詳細入力でできます（任意）
- **補完候補**：足りない攻撃・耐性を補えるタイプ／サブウェポン／ポケモンを、改善点の内訳つきで提案。6匹埋まっている場合は入れ替え候補として提案します

## スマホのホーム画面に追加（PWA）

- iPhone：Safariで開く → 共有ボタン →「ホーム画面に追加」
- Android：Chromeで開く → メニュー →「アプリをインストール」

## データについて

- ポケモン基本データ：PokeAPI（無料公開API）から取得し、`data/pokemon.json` に同梱（出典はファイル内に明記）
- 使用率：`data/usage.json`。取得元・期間・更新日はアプリの「環境対策」タブに表示されます。使用率%が公開されていない出典では順位のみを表示し、数値を推測で埋めることはしません。ダブル（VGC）のデータをシングルに流用することもありません
- 自動更新：GitHub Actions が約3日に1回、Smogon公式統計（Battle Stadium Singles系）の取得を試みます。失敗した場合は前回のデータを維持します（`.github/workflows/update-usage.yml`）

## 注意

- サブウェポンの提案は「タイプ」の提案です。そのポケモンが実際にその技を覚えるかは未照合なので、実戦投入前にゲーム内で確認してください
- レギュレーション使用可否は「M-Cリスト掲載」区分で絞り込めますが、最終確認はゲーム公式発表でお願いします

## 開発者向け

- DB再生成：`python3 scripts/build_db.py`（PokeAPIから一括取得、要ネット接続）
- テスト：`python3 tests/test_logic.py`
- 公開：このフォルダをGitHubリポジトリ `pokebuild` にpushし、Settings → Pages で公開（無料）
